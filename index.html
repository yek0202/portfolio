04Philosophy
My Philosophy

我怎么看待AI？

01
工具应服务于判断
好的工具不替代人的判断，而是把时间还给真正需要判断的事情。重复性劳动自动化，人只做决策。
02
从业务痛点出发
AI赋予了业务快速优化自身工作流和提高工作效率的机会，业务+AI不等于业务+IT。前者的协同效率要大得多。
03
持续迭代，快速验证
没有IT背景的业务也需要持续学习新型的技术，想象力越大，AI的能力越大。而人无法想象出自己没见过的东西。

趋势理解
AI 正在重塑"谁能写代码"的边界——非科班出身的业务人员可以用 Vibe Coding 构建生产级工具。
提升AI的能力边界的方式中，会写提示词是第一项，能用MCP、Rules、Hooks是第二项，能使用已经打通了交互的App是第三项。能力边界随着数据流的扩大而扩大。
供应链领域的 AI 落地不在于算法先进性，而在于对业务流程的深度理解和数据治理能力。
未来的 PMC 不是被 AI 替代，而是用 AI 放大自身的协调与决策能力。

关于这个网页的故事
对于个人简介的网页，我有一个更灵动的设计思路——用即梦生图生视频，用 Claude Code 为前端编程。

但是，很遗憾的是，就在5月15日上午9点16分，Claude Code 在思考了20分钟后，决定用一个"远古"版本的网页直接覆盖了我几乎完工的产品。Claude Code 又因为上下文太长，无法恢复。也怪自己上传 Git 的频率不够。

所以！先上传一个比较原始的个人简介，我的设计会持续更新！

其实我也是第一次做个人简介的网站，很多实现方式都在摸索。越摸索越震惊：AI 居然能帮我实现这个效果，那个效果。越做越兴奋哈哈。
